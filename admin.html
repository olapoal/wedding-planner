Integrasi Otomatis Webhook Lynk.id

Saat ada yang membeli di Lynk.id, email otomatis aktif tanpa perlu input manual!

Salin URL webhook di bawah ini dan tempelkan di menu Integrasi → Webhook pada dashboard toko Lynk.id Anda:

https://wedding-planner.netlify.app/.netlify/functions/lynk-webhook
Langkah Setup di Lynk.id:
1. Buka Dashboard Lynk.id → Settings → Webhooks.
2. Klik Tambah Webhook Baru, masukkan URL di atas.
3. Pilih event trigger: Order Selesai / Payment Success.
4. Simpan. Kini setiap kali ada yang beli, pembeli langsung bisa buka aplikasi cukup dengan email pembayaran mereka!
